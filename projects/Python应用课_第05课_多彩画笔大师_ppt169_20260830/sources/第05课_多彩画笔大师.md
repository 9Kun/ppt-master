## __本课知识讲解__

### __三种颜色命令__

pencolor设置线条颜色，fillcolor设置里面的颜色，color可以一次设置两者。颜色词统一用red、blue、green、yellow、pink、orange。

### __填充三明治__

begin\_fill像上面一片面包，中间是完整图形代码，end\_fill像下面一片面包，三者顺序不能乱。

### __背景与粗细__

Screen().bgcolor设置画布背景；pensize(6)和width(6)都能把线宽设为6。两者作用相同，本课各运行一次。

### __circle的两个数字__

circle(60)画圆；circle(60,180)画半圆。本课只修改半径和180，不讲几何原理。

### __动手练习A｜练习A：彩色圆__

__任务：使用width设置线条粗细并画圆。__

import turtle  
   
screen = turtle.Screen()  
screen.bgcolor("lightyellow")  
t = turtle.Turtle()  
t.pencolor("blue")  
t.width(6)  
t.circle(70)  
   
turtle.done()

__运行结果：__淡黄色背景上出现一个蓝色粗线圆。

__学生改一改：把width(6)换成pensize(3)，再比较线条粗细。__

教师支架：width和pensize作用相同；括号中只填一个简单数字。

### __动手练习B｜练习B：填充正方形__

__任务：使用填充三明治给正方形上色。__

import turtle  
   
t = turtle.Turtle()  
t.color("red", "pink")  
t.begin\_fill()  
for i in range(4):  
    t.forward(100)  
    t.right(90)  
t.end\_fill()  
   
turtle.done()

__运行结果：__红色边框、粉色内部的正方形。

__学生改一改：修改边框色、填充色和边长。__

教师支架：begin\_fill必须放在画图前，end\_fill必须放在封闭图形完成后。

### __动手练习C（拓展应用/微型PBL作品）｜微项目：海龟岛彩色徽章__

__任务：用两个填充圆制作双层徽章。__

import turtle  
   
screen = turtle.Screen()  
screen.bgcolor("lightblue")  
t = turtle.Turtle()  
t.speed(0)  
t.pensize(4)  
   
\# 外圈  
t.color("navy", "yellow")  
t.begin\_fill()  
t.circle(100)  
t.end\_fill()  
   
\# 内圈  
t.penup()  
t.goto(0, 35)  
t.pendown()  
t.color("red", "orange")  
t.begin\_fill()  
t.circle(65)  
t.end\_fill()  
   
turtle.done()

__运行结果：__得到有背景、双色边框和填充的双层圆徽章。

__学生改一改：从颜色卡中选两组颜色；可把内圈半径65改成50或75。__

教师支架：如果内圈位置不理想，只允许改goto的y数字，减少认知负担。
