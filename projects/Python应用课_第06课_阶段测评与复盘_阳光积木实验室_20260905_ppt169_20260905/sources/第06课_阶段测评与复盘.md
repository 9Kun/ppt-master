## __本课知识讲解__

### __单元工具箱整理__

把命令分成四盒彩卡：移动、重复、位置、装饰。学生说命令，教师放入对应盒子。

### __显示与隐藏海龟__

showturtle显示小海龟，hideturtle在作品完成后隐藏小海龟，让画面更整洁。

### __设置窗口标题__

screen.title("小红花画展")给窗口命名。让学生看见标题变化即可。

### __测试与修改__

按“先运行基础版—只改一处—再运行—保存”的顺序迭代，不允许一次改很多处。

### __动手练习A｜练习A：花瓣__

__任务：用循环画6片圆形花瓣。__

import turtle  
   
t = turtle.Turtle()  
t.speed(0)  
t.color("red", "pink")  
   
for petal in range(6):  
    t.begin\_fill()  
    t.circle(45)  
    t.end\_fill()  
    t.left(60)  
   
turtle.done()

__运行结果：__6个粉色圆形花瓣围成一朵花。

__学生改一改：把花瓣颜色改成orange、yellow或purple。__

教师支架：基础生不修改range(6)和left(60)，避免花瓣不能围成一圈。

### __动手练习B｜练习B：花心和花茎__

__任务：在花朵中心加圆点，并向下画花茎。__

import turtle  
   
t = turtle.Turtle()  
t.speed(0)  
t.dot(45, "yellow")  
t.setheading(270)  
t.pensize(8)  
t.pencolor("green")  
t.forward(140)  
   
turtle.done()

__运行结果：__黄色花心下面有一条绿色花茎。

__学生改一改：把花茎长度140改成100或180。__

教师支架：270度表示向下；先画花心再改变方向。

### __动手练习C（拓展应用/微型PBL作品）｜微项目：送你一朵小红花__

__任务：组合花瓣、花心、花茎并隐藏海龟。__

import turtle  
   
screen = turtle.Screen()  
screen.title("小红花画展")  
screen.bgcolor("lightblue")  
t = turtle.Turtle()  
t.speed(0)  
   
\# 花瓣  
t.color("red", "pink")  
for petal in range(6):  
    t.begin\_fill()  
    t.circle(45)  
    t.end\_fill()  
    t.left(60)  
   
\# 花心和花茎  
t.dot(45, "yellow")  
t.setheading(270)  
t.pensize(8)  
t.pencolor("green")  
t.forward(140)  
t.hideturtle()  
   
turtle.done()

__运行结果：__完成一朵有背景、花瓣、花心和花茎的彩色花。

__学生改一改：只选择修改背景、花瓣颜色或花茎长度中的1\-2项，并给窗口改标题。__

教师支架：若图形混乱，回到基础版逐段运行；不要求学生从空白重新输入全部代码。
