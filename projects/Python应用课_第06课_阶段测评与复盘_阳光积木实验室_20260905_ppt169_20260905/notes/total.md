# 02_今天的120分钟
今天的一百二十分钟分成四关：十题热身、新命令实验、选择挑战和作品工坊。选择挑战后先保存，再休息十分钟；最后每个人都要运行作品、说明修改并完成离堂复盘。

# 03_今天要带走什么
上排是三个学习目标：综合旧命令、认识新命令、完成小红花。下排是两项可观察表现：一次只改一处并马上运行，以及正确保存、清楚展示。通关时要同时做到能运行、结构完整和会解释修改。

---
# 04_十题热身赛
热身前先把旧命令放进五个工具盒：移动转向、循环次数、坐标回家、颜色填充、背景与圆。接下来的十道题都从这五盒里来；每题先口答，再点击揭晓，答错就马上完整修正。

---
# 05_抢答规则
先独立思考，再举手或用手势作答，最后点击答案。回答时不只报命令名称，还要说出它完成什么任务；发现错误就立即修正。

---
# 06_热身1-2_起步命令
第一题回忆怎样导入海龟模块，正确写法是 import turtle。第二题回忆怎样让海龟向前移动，常用命令是 forward。请先回答，再分别点击右侧区域核对。

---
# 07_热身3-4_重复动作
第三题考查重复结构，for 循环可以让一组动作反复执行。第四题考查次数来源，range 生成循环所需的序列。请说明 range 括号里的数字怎样影响重复次数。

---
# 08_热身5-6_位置导航
第五题回忆 goto 或 setpos，它们能把海龟送到指定坐标。第六题是 home，它会让海龟回到原点并恢复默认方向。揭晓后，请比较“去指定地点”和“回家”的区别。

---
# 09_热身7-8_颜色填充
第七题回忆 pencolor 或 color，它们控制线条和填充颜色。第八题是一对命令 begin_fill 与 end_fill，只有把要填充的封闭图形包在中间，颜色才会填进去。

---
# 10_热身9-10_背景与圆
第九题用 Screen().bgcolor 设置窗口背景。第十题用 circle 绘制圆形，也是本课花瓣和花心的重要基础。完成两题后，把十个旧工具和即将开始的小红花项目连接起来。

---
# 11_项目启动_送你一朵小红花
驱动问题是怎样综合海龟命令，画出一朵会旋转的彩色花。作品要有花瓣、花心和花茎，还要能够运行和展示；作者需要指出自己改过的一处并解释理由。

---
# 12_成功标准先看清
成功作品首先必须稳定运行，其次结构完整，最后能够说清修改。今天不比谁改得最多，而是比谁能用小步测试保证每一次修改都有依据。

---
# 13_新命令小实验
这一站学习三个新工具：让海龟出现、让海龟退场、给窗口起名字。它们帮助作品更整洁、更会自我介绍，也更方便我们观察和调试。

---
# 14_四盒命令工具箱
把旧命令分成四盒：移动、重复、位置和装饰。分类不是为了背表格，而是遇到任务时能快速找到合适的积木。请为每一盒举出一个已经用过的命令。

---
# 15_显示与隐藏海龟
showturtle 会让海龟光标出现，适合观察绘制过程。hideturtle 会让光标隐藏，适合展示最终作品。两条命令只改变光标是否可见，不会擦掉已经画好的图形。

---
# 16_海龟显隐实验站
先选择“显示海龟”或“隐藏海龟”，左侧代码会切换到对应命令。点击运行后，状态先变成运行中，终端再逐字输出结果，完成后显示成功提示。可以反复切换任务和运行，比较 show 与 hide 的效果。

---
# 17_给窗口起名字
先创建窗口对象 screen，再调用 screen.title。标题文字必须放在引号里；不要写成 t.title，因为 t 是画笔海龟，而 screen 才是窗口。点击后观察标题效果。

---
# 18_窗口标题实验站
顶部三个任务会切换不同的窗口标题代码。每次选择后再点击运行，终端逐字显示本次标题，旧输出会重置。请观察只有引号中的文字变化，调用结构保持不变。

---
# 19_安全修改四步法
安全调试分四步：先运行基础版，只改一处，再次运行，确认后保存。这样一旦出现问题，就能迅速定位是哪一处修改造成的。最后点击理解为什么不能同时改很多地方。

---
# 20_练习A_六片花瓣
一片花瓣可以用圆形动作得到，循环六次就形成六片花瓣。每完成一片左转六十度，六次正好转完三百六十度。先预测把 range 改成八会发生什么，再运行验证。

---
# 21_花瓣颜色实验站
选择红花、橙花或紫花，观察代码中只有颜色参数改变。点击对应运行按钮后，终端按步骤逐行出现，并在最后显示相应花朵预览。代码、输出与预览必须彼此一致。

---
# 22_八题选择挑战
接下来用八道选择题检查理解。每题先举手或用手势选择，再点击揭晓；绿色表示正确，粉色提示易错点，解析要回答为什么。

---
# 23_选择题1-2
第一题正确答案是 hideturtle，用于隐藏海龟。第二题正确答案是 showturtle，用于显示海龟。可以用 hide 和 show 的英文含义帮助记忆。

---
# 24_选择题3-4
窗口标题通过 screen.title 设置。六瓣花把一圈平均分成六份，所以每次转六十度。请口头说出三百六十除以六的计算关系。

---
# 25_选择题5-6
作品完成后隐藏海龟会让画面更整洁。二百七十度表示向下，适合画花茎；可以用身体转向复习零度向右、九十度向上和一百八十度向左。

---
# 26_选择题7-8
改一处后马上运行，是最安全的调试方法。本课目标是综合命令完成作品，而不是追求代码最长。把“小步测试”和“综合应用”两个关键词连起来理解。

# 27_课间保存站

# 28_练习B_花心和花茎
先独立补全花心和花茎，再点击核对。关键命令依次包括 dot、setheading、pensize、pencolor 和 forward。黄色圆点是花心，二百七十度让花茎向下，forward 的数值决定花茎长度。

---
# 29_花茎长度实验站
依次选择短、标准和长三种花茎。每次只修改 forward 的数字，再点击运行比较结果；终端逐行说明设置方向、绘制花茎和完成。请用参数变化解释画面变化。

# 30_微项目装配站
现在把花瓣、花心和花茎装配成完整作品。可以从背景、花瓣颜色、花茎长度或窗口标题中选择一到两项修改，但每次只改一处并立即测试。

# 31_完整作品代码地图

# 32_小红花作品实验站

# 33_五步完成桌面画展
完成作品要依次做到运行基础版、选择一处修改、再次运行、隐藏海龟并设置标题、最后保存。请跟着点击顺序逐步完成，不要跳过再次运行这一关。

# 34_作品验收与同伴建议
展示时用四句话介绍：我的作品是，我使用了，我修改了，下一次我想。听众只给一条具体建议，重点检查能否运行、结构是否完整，以及作者能否解释修改。

---
# 35_三个常见问题
程序太慢时检查 speed 是否设为零；花茎方向不对时检查 setheading 是否为二百七十；花茎过长时只调整 forward。遇到问题先定位参数，再做一次小改动并重新运行。
