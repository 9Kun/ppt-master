[P20] 本课知识讲解
[P21] while像值班守卫
[P22] 只要门还没打开且次数没用完，就继续询问。条件不成立时循环停止。
[P23] 计数防止不停
[P24] tries从0开始，每问一次加1。使用while tries < 3保证最多问3次。
[P25] break立刻离开
[P26] 口令正确时break，马上跳出整个循环。用“提前下车”手势帮助记忆。
[P27] continue跳过本轮
[P28] 输入空白时continue，跳过下面的判断，回到下一轮。for适合次数清楚，while适合看条件继续。
[P29] 动手练习A｜练习A：数到3停
[P30] 任务：使用while重复输出并让计数增加。
[P31] count = 1
 
while count <= 3:
    print("第", count, "次检查")
    count = count + 1
 
print("检查结束")
[P32] 运行结果：依次输出第1、2、3次检查，然后结束。
[P33] 学生改一改：把3改成5，观察输出次数。
[P34] 教师支架：不能漏掉count=count+1，否则循环可能不停。

[P44] 动手练习C（拓展应用/微型PBL作品）｜微项目：三次口令门
[P45] 任务：限制三次，空输入用continue跳过判断。
[P46] secret = "python"
tries = 0
 
while tries < 3:
    password = input("请输入特工口令：")
 
    if password == "":
        print("不能输入空白！")
        continue
 
    tries = tries + 1
 
    if password == secret:
        print("身份确认成功，欢迎特工！")
        break
    else:
        print("口令错误。还可尝试", 3 - tries, "次。")
 
if password != secret:
    print("三次机会已用完，任务暂停。")
[P47] 运行结果：空输入不计次数；正确提前成功；三次错误后停止。
[P48] 学生改一改：只修改secret的内容，并用“空白、错误、正确”三种输入测试。
[P49] 教师支架：若学生对continue困难，基础版可删除空白分支，保留三次限制与break。
